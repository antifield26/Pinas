## 二、v1.10.0 实施清单（P0 + P1 全部完成）

### P0 安全根治
1. **P0-1 DNS 重绑定**：`agent.rs` 请求时 `tokio::net::lookup_host` 真实解析 + 私网/环回/CGNAT/文档网段过滤（`is_private_ip`）+
   任一私有结果即拒绝 + `reqwest::Client::resolve()` 连接 IP 钉扎（SNI 仍为域名）；按 base 缓存 10 分钟；禁止代理。
2. **P0-2 会话空闲超时**：schema v11 `sessions.last_active_at`；绝对过期（7 天）+ 空闲超时（默认 24h，
   `PINAS_SESSION_IDLE_MINUTES`）双闸；中间件惰性刷新（≥5 分钟写一次）；登录创建即记活跃；后台任务定期清理。
3. **P0-3 AI key 落库加密**：`core::secrets` ChaCha20-Poly1305（随机 12B nonce），格式 `enc:v1:base64(nonce||ct||tag)`；
   主密钥 = `PINAS_MASTER_KEY`（64 hex）或 `<data_dir>/secret.key`（0600 自动生成）；旧明文读取兼容、下次保存升级；
   密钥文件损坏拒绝启动（防密文永久不可解）；settings 读写 + agent 解析三处接线。
4. **P0-4 符号链接 TOCTOU**：`src/fsutil.rs` `Sandbox` = `openat2(RESOLVE_BENEATH|NO_MAGICLINKS)` + `renameat/unlinkat/mkdirat/statat` 族；
   O_PATH 父目录 fd + *at 最终组件（删除/重命名不跟随链接本身）；沙箱内相对链接可用、绝对链接保守拒绝；
   覆盖 media（流/编辑器/zip 打包）、file_ops（建目录/改名/移动/批移动/回收站/预览/列表对账）、dav（全方法）、
   share（下载/目录列表）、trash（还原/删除/清空/自动清理）、journal 重放、upload merge、agent read_file 工具；
   字符串级 `safe_join_sandbox` 保留为纵深防御第一层。新增 4 项越界集成测试 + 3 项 fsutil 单测。

### P1 工程治理
5. **P1-1 模块拆分**：`file_ops.rs` 1796 行 → `file_ops/{mod,core,api,fragments}.rs`（核心逻辑/JSON API/HTMX 片段）；
   `dav.rs` 1351 行 → `dav/{mod,auth,ops}.rs`（入口分发/认证/方法实现）。行为零变化（80 测试回归通过）。
6. **P1-2 X-Request-Id**：`middleware/request_id.rs` 最外层中间件——沿用入站 ID、响应头 + tracing span（request_id/method/uri）；
   dsh 反代注入上游请求头（跨进程链路贯穿）。集成测试 1 项。
7. **P1-3 供应链**：`deny.toml`（advisories+yanked deny、宽松许可白名单 15 项、多版本 warn）；CI 增加
   `embiid/cargo-deny-action@v2`；`.github/dependabot.yml`（cargo 每周 + actions 每月）；Cargo.toml 补 `license = "MIT"`；
   `spin 0.9.8→0.9.9`（yanked 修复）。本地 `cargo deny check` 全绿。
8. **P1-4 配置收敛**：secret 掩码清单扩展（DEEPSEEK_API_KEY / MASTER_KEY 同密码只打 ✓）；启动日志带空闲超时参数。
9. **P1-5 文档**：CLAUDE.md 去漂移（结构图/测试计数/环境变量/已知边界重写为 v1.10 状态）+ 本复盘记录 + 版本 1.10.0。

## 三、已知边界（v1.10 后状态）

- **unsafe-eval**（Alpine x-data / htmx hx-on）：接受项，不安排移除（迁移收益不划算）。
- 绝对路径符号链接在沙箱内整体拒绝（比 std::fs 更严格的保守语义）。
- 分享失败锁定为内存态（重启清零）；upload_limit_mb 语义 = 全局 body limit（历史语义，文档已注明）。
- 登录响应回显会话 token（dsh-plugin-pinas Bearer 依赖）。
- DNS 解析走系统解析器（解析器本身可信）。

## 四、后续方向（v1.11+ 候选，未决策）

- P2 功能：内容去重/秒传、Web Push 待办提醒、分享分级（文件夹/过期/读写）、PDF/Office 预览、zip 流式压缩、审计 UI。
- 长期：dsh 插件 + AI 工具扩展（Web 搜索/邮件/相册/MC 运维动作），把 NAS 变成「可对话的运维助手」。
- 不建议：Postgres / 微服务 / SPA / 消息队列（单节点全部负收益）。
